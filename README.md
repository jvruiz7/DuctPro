# DuctPro

Software para dutos retangulares: cálculo, planificação, nesting e corte a laser.

## Instalação

Baixe o instalador `DuctPro_Setup_x.y.z.exe` da [versão mais recente](../../releases/latest) e execute-o.

## Atualizações

O DuctPro procura versões novas ao abrir e pelo botão **⟳ Atualizações**, baixa o instalador desta página e se atualiza sozinho.

Este repositório contém apenas os instaladores publicados.
